# crypto_trade_tool

暗号資産トレード支援ツール。

## 開発

このリポジトリは [Claude Code](https://claude.com/claude-code) と、PMO型AIオーケストレーター **Jen** を使って開発します。Jen のセットアップは `.claude/settings.json` に定義されています（`jen-marketplace` から自動で登録・有効化）。

```
/jen:jen conduct
Goal: ...
```

詳細は [youki0p0/jen-marketplace](https://github.com/youki0p0/jen-marketplace) を参照してください。
